# JobTrack Backend

Spring Boot REST API for the JobTrack application.

## Requirements

- Java 21+
- Maven
- MySQL

## Start

1. Create the `jobtrack` database.
2. Update `src/main/resources/application.properties`.
3. Run `JobTrackApplication.java`.

Server:

`http://localhost:8080`

API:

`http://localhost:8080/api/jobs`
